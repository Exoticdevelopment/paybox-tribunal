What a certificate proves

The promiseThe exact contract version and hash the result was judged under.
The evidenceThe hash of the exact output evaluated, every rule result, and the AI judge's ruling.
The paymentBound to the buyer's signed authorization and its nonce, so it can't be reused for another payment.

It does not prove the output is true, and it can't stop a seller from settling outside Tribunal. That's why every verdict is also public.

Verify it yourself, without this page

Node.js, no dependencies:

import { verify } from "node:crypto";

const base = "https://paybox-tribunal.onrender.com";
const { certificate, signature } = await (await fetch(`${base}/certificates/CASE_ID`)).json();
const { publicKey } = await (await fetch(`${base}/certificates/key`, { headers: { accept: "application/json" } })).json();

const canonical = (v) => Array.isArray(v) ? v.map(canonical)
  : v && typeof v === "object" ? Object.fromEntries(Object.keys(v).sort().map((k) => [k, canonical(v[k])])) : v;

console.log(verify(null, Buffer.from(JSON.stringify(canonical(certificate))), publicKey, Buffer.from(signature, "base64")));
